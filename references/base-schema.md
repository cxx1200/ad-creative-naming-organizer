## 命名模板库

这是唯一命名规则来源。每个项目可有多条模板记录：

- `项目名称`：text
- `模板名称`：text
- `命名模板`：text，`{字段}` 必填，`{字段?}` 可选
- `字段取值字典`：text，每行一条 `字段=值1,值2,值3`，兼容 `字段: 值1,值2,值3`
- `字段取值字典` 中可额外写一行 `比例格式: 三码`，支持 `三码`（默认）、`x` 或 `冒号`
- `归一化说明`：text，优化师用自然语言描述文件名预处理规则
- `归一化规则`：text，每行一条 `匹配正则 => 替换模板`，脚本在模板匹配前执行
- `示例`：text
- `优先级`：number，越小越优先
- `是否启用`：text 或 select，取 `启用` 或 `停用`

脚本只读取 `是否启用=启用` 的记录，并按 `优先级` 升序使用。项目存在性由“该项目至少有一条启用模板”判断。脚本先按 `优先级` 顺序收集所有启用模板的 `归一化规则`，逐行执行 `re.sub(匹配正则, 替换模板)`；自然语言说明不直接执行，用于维护和大模型生成/校验机器规则。

当模板中需要 `比例`、`尺寸` 或 `分辨率`，但文件名中无法解析时，脚本会读取媒体文件尺寸并自动补全。`字段取值字典` 中未写 `比例格式` 时按 `三码` 处理；写 `x` 或 `冒号` 时，会将识别结果输出为 `1x1/4x5/9x16/16x9` 或 `1:1/4:5/9:16/16:9`。

## 预览整理表

已有表，脚本补充以下字段：

- `项目名称`
- `文件路径`
- `文件原名`
- `是否命中`
- `建议新文件名`
- `初始建议新文件名`：保存 AI 首次生成值，用于识别人工修改
- `执行状态`：`待审核`、`已确认`、`已执行`、`跳过`、`冲突`
- `存档路径`
- `处理备注`

预览按 `项目名称 + 文件路径` 幂等更新。若已有记录中 `建议新文件名 != 初始建议新文件名`，脚本视为人工修改并保留。

为控制预览表读取量，脚本在 Base 端先按项目过滤，并跳过 `执行状态=已执行` 的历史记录；已执行记录仍保留在预览表中供人工查看，不参与后续幂等匹配。
